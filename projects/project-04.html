PROJECT 04 / NETWORK AUTOMATION

Network Automation & Deployment: Python, Ansible, & Netmiko

Secure, repeatable network configuration, VLAN deployment, SSH administration, automated backups, and validation.

01 / THE CHALLENGE

Engineering Problem

Manual network configuration across multiple switches increases operational complexity, introduces configuration inconsistencies, and creates opportunities for human error. Without standardized automation, configuration backups, VLAN deployment, administrative access, and change verification require repetitive engineering effort. Network operations teams need secure, repeatable, and auditable deployment processes that improve configuration consistency, reduce downtime risk, and support scalable infrastructure management.

02 / THE APPROACH

Technical Solution

Developed a network automation solution using Python and Netmiko to establish device connectivity, collect configuration backups, discover existing VLANs, and support automated configuration changes. Implemented Ansible inventory files and YAML playbooks to standardize VLAN deployment, configuration verification, and administrative account provisioning across ExtremeXOS switches. Integrated SSH key-based authentication, GitLab version control, connectivity testing, and structured validation to establish a repeatable and secure network deployment workflow.

03 / THE VALUE

Business & Technical Value

Business Value:

  • Reduce deployment time and manual configuration effort through standardized network automation and repeatable workflows.
  • Improve operational reliability and business continuity through automated configuration backups, change validation, and consistent VLAN deployment.
  • Strengthen security, accountability, and scalability through SSH-based administration, version-controlled configurations, and documented engineering procedures.

Technical Value:

  • Demonstrate Python scripting, Netmiko automation, ExtremeXOS switch management, configuration discovery, and automated backups.
  • Implement Ansible inventories, YAML playbooks, VLAN provisioning, configuration validation, and administrative account automation.
  • Apply SSH key-based authentication, GitLab version control, network connectivity testing, troubleshooting, and repeatable deployment validation.

05 / PROJECT EVIDENCE

Implementation & Validation Highlights

  • Network Discovery & Configuration Backups: Established SSH connectivity to four ExtremeXOS access switches, automated configuration backups using Python and Netmiko, and discovered existing VLAN configurations to establish a verified infrastructure baseline.
  • Automated VLAN Deployment & Verification: Implemented standardized VLAN configurations across IT, Management, Accounting, and User networks using automation workflows; validated VLAN assignments, switch connectivity, and configuration consistency through repeatable verification procedures.
  • SSH Security, Ansible & Version Control: Configured SSH key-based authentication, developed Ansible inventory files and YAML playbooks for administrative provisioning, maintained configuration backups through GitLab, and documented testing, troubleshooting, and deployment evidence.
